# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

- on GitHub, **Security → Report a vulnerability** on this repository, or
- by email to gisterecis@moldchem.com.

Include the browser and its version, the extension's version, and the steps to reproduce. You should get a reply
within a week. Once a fix is published in the stores, the report can be made public, with credit if you want it.

## Supported versions

Only the latest version on addons.mozilla.org and the Chrome Web Store gets security fixes.

## Scope

In scope: anything that lets a web page or a third party run code in the extension, read data through it, or make it
send requests; the selected text leaving the browser; the extension contacting hosts other than the banks' public
rate pages and the National Bank of Moldova.

Not security issues: wrong or outdated exchange rates, or a bank's site changing so that its rates can't be read.
Please open a normal issue for those.
